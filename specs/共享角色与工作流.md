# 共享角色与工作流

## 已确认边界

- Agent、工作流和模型连接属于工作空间，不属于任何项目。
- 工作流引用角色的固定发布版本；发布工作流只产生工作流版本，不复制或发布角色。
- 模型连接由 Agent 选择，不进行项目模型连接使用授权检查；密钥仍从服务端原始配置读取。
- 项目只在任务、试运行、定时任务或 Webhook 的执行配置中指定，提供代码、工作区和项目操作权限。
- 不再需要“共享模板绑定到项目”。内置角色预设只负责填充新草稿。
- 已有相同配置副本合并展示，不删除旧对象、发布版本和历史运行引用；不同配置保留。

## 验收条件

1. 不选择项目也能查看、创建、编辑和发布工作空间内的 Agent、工作流、模型连接；保留工作空间配置管理权限。
2. 新建任务的选择器按工作流、Agent 分组；切换项目不会复制配置或改变候选定义。
3. 同一发布版本可在不同项目执行，任务必须明确项目，并独立检查该项目的运行权限。
4. 工作流保存、发布时校验角色引用、交接契约与拓扑；发布不创建任何 Agent。
5. 工作流固定引用旧角色版本；角色新版本不自动改变已发布工作流。
6. 模型连接可跨项目使用；取消 PANGU_CONNECTION_GRANTS，保留凭据格式、端点格式、登录和模型可用性检查。
7. 试运行列表按执行项目过滤，不能因角色共享而暴露其他项目的任务记录。
8. 定时任务、Webhook、工厂生成配置、导入导出、预检和重试均遵循同一归属模型。
9. 迁移不修改已有发布版本正文，不删除历史引用。相同副本归档，工作流草稿引用可换为配置相同的保留版本；不同配置不按名称合并。
10. 原有权限、沙箱、隔离工作区、取消、trace 与节点调试继续生效。

## 实现范围

配置数据库约束与迁移；catalog 定义、引用、编译和列表；API 权限和提交参数；试运行和自动化；工厂配置写入；OpenAPI 与生成类型；配置页面、工作流画布、任务选择器；对应测试、示例和使用说明。

运行快照继续包含 project_id。定义对象不再接受 project_id；不增加兼容旧绑定请求的分支。正式库迁移使用新编号，已部署的 0041、0042 不修改。

## 副本合并规则

同工作空间、类型和名称的对象，只有当前草稿、最新发布配置及历史配置集合均一致时才合并；比较忽略旧 `template_version` 来源字段。保留最早对象，其余对象归档并记下保留对象。旧对象、版本 ID、版本正文和运行记录不删除；旧版本仍可供既有自动化使用，是否允许新运行由保留对象的归档状态决定。草稿中的重复角色引用改为等价保留版本，已发布流程正文不改写。

不同配置保留为独立角色；同名不代表相同配置。历史绑定回执表仅用于追溯，已移除绑定 API 和界面入口。模型连接不合并，以免影响原凭据引用与归档状态。
