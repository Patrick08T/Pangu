# 运行契约与验收样本

## 可视化定义

控制台通过画布和表单生成工作流，不要求用户编写配置文件。`Flow.editor` 保存节点显示名称、位置及画布视图，随草稿和发布版本持久化，编译执行时忽略。未完成草稿允许零节点和暂时失效的连线引用；草稿仍校验结构、预算、输入字段结构及同工作空间 Agent 版本引用。发布时完整校验 DAG、条件、审批、Codex 工作区限制及已声明结构的字段路径与类型。没有声明输出结构的引用在运行时校验。发布版本不可变，定时任务仍固定版本。

## 状态和查询

### Agent 交接契约

节点 `handoff` 包含 `objective`、`inputs`、`deliverables`、`acceptance`、`failure_handling` 五项文字。每项最多 4096 UTF-8 字节。未完成草稿允许缺项或空白；发布共享 Agent、工作流以及首次接受试运行、正式运行、人工重跑、返工和 Cron 触发时必须完整。发布版本与运行快照保存原文，执行时传给 Eino 或原生 Codex，不缓存或补写历史配置。

升级前已接受的请求可按原幂等键恢复；同一运行的节点自动重试/重启恢复不视为新任务。旧发布版本仍可读取，首次新任务必须使用补齐契约后发布的新版本。缺少契约且未创建提交回执的 Cron 触发记为 `skipped`，原因指出缺项，同时释放对应活动槽；更新计划后可继续触发。不能因缺契约终结已关联提交回执的触发。

契约描述协作要求，不扩大任务资料授权、工具、预算或文件权限。文字验收标准通过指令传递；结构化输出继续由 `output_schema` 校验，交付质量仍需证据或人工核验。

### Agent 草稿试运行

`POST /catalog/{id}/draft/preflight` 只诊断，不提交模型任务；`POST /catalog/{id}/trials` 接受 `{revision,input}` 并固定服务器当前草稿。`GET /catalog/{id}/trials?offset=0` 分页返回来源修订和请求回执，正文通过既有运行接口查询。草稿试运行不创建发布版本，也不能用作工作流或 Cron 的固定引用。

提交的 `Idempotency-Key` 为 `Unix毫秒时间戳.UUID`。同项目、操作者、对象、修订和输入返回同一回执，内容变化返回 409；接受后草稿更新或归档不改变回执和快照。89 天重试窗口到期返回 409，旧记录清理后也不会重新派发。键时间超前超过 5 分钟时拒绝。首次接受的项目运行权限在身份锁下重新验证，修订检查、提交快照和草稿来源关联同事务落库；后续复用既有派发与对账路径。

### 运行状态

| Hatchet | Pangu | 含义 |
| --- | --- | --- |
| QUEUED | queued | 已接受，等待调度 |
| RUNNING | running | 执行中，含等待子任务和持久恢复 |
| COMPLETED | succeeded | 编排成功结束 |
| FAILED | failed | 重试耗尽或不可恢复失败 |
| CANCELLED | cancelled | 调度已取消；文件清理和执行器停止证据单独确认 |
| 未知值 | unknown | 不推测成功或失败，保留诊断 |

取消请求是独立意图。发送取消成功只返回已接受，未证实执行器停止前不得把业务运行标为安全终止。取消和重跑路由以 OpenAPI 为准。

`GET /runs` 支持 offset、limit（1–100，默认20）、status、since、until（RFC3339）。首屏默认最近90天，并返回固定时间边界，后续页沿用这些边界。按产品提交时间、运行 ID 降序分页；状态筛选在当前页应用，空页仍可能有下一页。执行状态实时变化，调用方按 ID 合并并支持刷新。查询只包含当前命名空间及授权项目的根运行。

`GET /runs/{id}` 返回产品字段，节点按 node_id 排序。真实节点 attempt 从 1 开始，Hatchet retryCount 加1；跳过和复用节点为0，其 UUID 是稳定的产品显示标识，不代表新建 Hatchet 任务。不把模型回复当作工具执行证据。不返回凭据或原始调度输入。新提交可能短暂404，应按 Location 重试查询。

自动重试/重启恢复沿用同一运行与节点身份；人工重新运行必须新建运行，固定原始定义、输入及 Git 基准，并链接来源运行。基准不存在时拒绝重跑，不取最新分支。

检查点返工使用 `POST /runs/{id}/fork`，与整次重跑区分。只复用串行无条件 Codex 成功前缀；定义变化使该节点及后续失效，全局输入改变使全部失效。记录父运行、选中节点、原始基准、实际复用节点与请求摘要；旧历史不覆盖。对返工运行再做整次重跑时，从最初 Git 基准执行全部节点。来源清理后，已接受返工仍可在自身幂等记录保留期内以原键/原输入/原发起人找回。

条件 `when` 只允许布尔或字符串精确匹配，字段来源为 `$input` 或直接上游的结构化输出。未命中时生成 `skipped` 产品节点，不派发 Agent；任何直接上游跳过会使后续依赖节点跳过，不提供自动合并互斥分支的语义。

人工审批通过 Hatchet 持久等待恢复；只保留独立审批期限，取消整次运行的 6 小时业务期限。人工采纳必须来自飞书会话并绑定当前产物摘要，API Token 不能代填。专用交付 ZIP 要求实施与只读审查两节点真实验证成功、运行确认停止、当前产物经人采纳。普通产物下载用于检查，不代表业务验收通过。

临时输入、日志和产物保留30天，运行/请求摘要保留90天，审计保留180天。Hatchet core/OLAP 统一配置720小时；产品库独立保存确认终结的无正文摘要。远端明细到期后，详情返回摘要和 `logs_expired`，事件返回410；无法确认的状态为unknown，不能推测成功。发布配置不随运行清理。

## 客观验收样本

选择 Pangu 自身作为第一个真实项目。在独立 clone 内新增 `docs/agent-acceptance.md`，内容必须为中文且包含“任务目标”“验收标准”“风险”三个标题；不得修改任何其他文件。

编排：Eino 产品经理整理简短目标 → Codex 创建文件 → 只读验证。客观验收：Git 差异只有该新文件，文件 UTF-8 可解码，三个标题均存在，源仓库工作区与 HEAD 未改变，`go test ./...` 退出码为0。最终报告必须引用真实命令退出码与文件摘要，不能由模型声称测试通过。

模型供应商、费用上限和真人采纳结果未配置前，此样本只作为可执行验收规范，不计为真实完成。

## 行为追踪与节点调试（2026-10-28）

`policy` 只包含 `retries`；旧的 `timeout_seconds`、`tool_calls` 不再是有效请求字段，导入配置需删除它们，审批自身的 `timeout_seconds` 保留。未设置 `budget` 时不施加默认调用上限；设置后按原来的显式额度原子预留。

`GET /runs/{id}/debug` 返回持久暂停状态、单步许可、版本和活动尝试数；`POST` 接收 `{action: pause|resume|step, revision}`。控制需要当前项目运行管理权限与会话 CSRF，写入时重新授权并审计。版本过期、已取消、终态或单步时仍有活动节点返回 409。

暂停只阻止尚未开始的节点尝试，已开始的执行继续完成。单步放行一个就绪节点尝试；若失败需重试，重试也等待下一次单步或继续。根派发与尝试开始共同检查持久闸门，取消仍可终止进程树。重放不新增调度调用序列；暂停等待占用当前 Worker 槽位，不是操作系统挂起。人工审批、依赖和分支条件继续生效。

`GET /runs/{id}/trace` 支持 `node/kind/status/after/before/limit`，按递增提交序号倒序分页；使用 `next_before` 读取更早记录。界面每 2 秒刷新最新页。`trace.ndjson` 导出相同筛选下的全部记录，开始后的新增记录不纳入；末尾 `export_error` 表示导出不完整。

事件含运行、节点、尝试、span/父 span、开始/结束、模型请求摘要、工具参数/结果、耗时、状态和错误。输入/输出/错误各最多 8192 字节，截断有标记；入库前脱敏，不采集认证头或模型内部思维链。节点停止后，缺少完成回执的 span 标记为中断，不能推断成功或外部副作用已回滚。追踪正文按运行保留期清理，晚到事件不得复活正文。
