# 对话式 Agent 工厂使用与验收

日期：2026-10-27。入口：<http://127.0.0.1:8081/#/factory>。

## 使用方式

1. 选择项目，进入“工厂助手”，开始新对话。系统读取工作空间已发布的模型连接；本机已有 Worker Codex 账号，可直接选择。
2. 用自然语言描述要完成的工作、授权资料和交付物。生成助手会澄清缺项或返回候选，自动填写 Agent 职责、五项交接契约和流程步骤。
3. 查看助手权限、指令、交接契约及流程画布。继续发送修改要求会生成新的完整候选。
4. 点击“确认创建并发布”，系统在同一数据库事务中批量创建/修改 Agent、发布版本、绑定工作流并发布。任一对象失败全部回滚。
5. 发布回执提供真实资源链接和“运行此助手/流程”入口。在运行页填写本次任务输入并点击“开始执行”，才正式执行任务。对话中提到“运行”时，助手会指向此入口，不替用户猜测输入或授权来源。

生成本身会调用模型；每轮上限为一次模型调用、一次 Codex 会话、零搜索、零工具、零重试。查看历史、预览和确认发布不会调用模型。可以打开生成任务记录并请求停止；状态会在执行器确认停止后更新。

## 修改与优化

- “修改现有配置”：选择当前项目的 Agent 或流程。预览展示 Agent 字段差异、工作流依赖变化，应用时再次检查目标修订号。历史发布版本、已有计划和在途任务不被替换。
- “诊断任务”：选择当前项目已结束且未过期的任务，以节点结果及错误作为证据；可以只给解释，不产生配置。
- “基于证据优化”：同时选择配置目标和任务。允许调整指令及已有步骤，但不能扩大文件权限、工具次数、超时、重试或总预算，不能改变交接/输出契约、角色、执行器、连接和审批门槛。有审批的工作流还固定步骤、依赖和条件。扩大职责或改变审批结构应明确选择修改模式。
- 优化输出只是候选，未经独立评测不能宣称质量提高。固定样本和人工采纳仍使用现有评测功能。

## 持久化、权限与边界

会话固定项目，发起人及项目管理者可继续操作，项目查看权限控制读取。API Token 使用工厂操作时还需 `manage_factory`；生成同时需要 `configure`、`run`。权限在事务身份锁内重新检查。

消息 UUID 绑定固定请求与生成快照，刷新或网络重试不会创建第二次模型任务；同一候选重复确认返回原发布回执。新消息、并发编辑或正文清理导致修订号变化时，旧请求会被拒绝。生成结果由既有后台维护循环同步，即使用户关闭页面也会保存。

正文保留 30 天，历史元信息与资源链接保留 90 天；活动生成受保护。清理与追加/应用共用会话锁，并递增修订号，避免已清理内容再次进入生成上下文。首条消息过期时同步清理对话标题。审计沿用现有 180 天规则。

首版每个会话最多 20 轮，每条消息最多 8000 UTF-8 字节，候选最多 12 个 Agent、32 个步骤，生成输出沿用 16 KiB 节点限制；大方案应分阶段创建。输入资料过大时明确报错，不静默截断。不包含循环、动态代码执行、任意 MCP/插件、长期记忆或自动运行优化循环。
