# 个人登录凭证固定 30 天：验证与审查

## 已确认行为

用户选择：飞书授权登录后，由 Pangu 签发绑定个人身份的登录 token，固定 30 天后过期。

- 飞书授权流程、允许租户及成员身份检查保留。
- Pangu 随机登录 token 使用 HttpOnly Cookie；数据库只存摘要和用户归属。
- Cookie Max-Age 与数据库 expires_at 共用 2,592,000 秒（30×24 小时）的时长。访问不续期；退出登录、禁用账号立即阻止继续访问。
- 重新登录替换当前旧会话。升级前已签发的会话保留原到期时间，新规则从重新登录开始生效。
- 不更改飞书签发令牌的期限，不更改独立的项目 API Token 机制，不增加本地免认证登录入口。

## 修改范围
