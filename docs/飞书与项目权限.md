# 飞书与项目权限

当前代码已支持后端飞书授权、Pangu 会话和项目权限；真实应用联调需要主机管理员完成以下配置。密钥不放入仓库或聊天。

## 接入配置

在飞书开发者后台创建自建应用，启用网页登录并登记精确回调：`PANGU_PUBLIC_URL/api/auth/callback`。只使用基础身份信息，不申请通讯录全量同步、文档或消息权限。

| 环境变量 | 含义 |
| --- | --- |
| `PANGU_PUBLIC_URL` | 浏览器访问的源地址，无路径或末尾斜杠；远程必须 HTTPS，本地允许回环 HTTP |
| `PANGU_FEISHU_APP_ID` / `PANGU_FEISHU_APP_SECRET` | 当前自建应用身份，Secret 仅 API 服务持有 |
| `PANGU_FEISHU_TENANT_KEY` | 唯一允许的飞书租户 |
| `PANGU_FEISHU_ADMIN_OPEN_ID` | 明确指定首位管理员在当前应用下的 open_id |

开发时若页面位于 `http://localhost:5180`，PUBLIC_URL 使用该地址，由 Vite 将 `/api` 转发到后端。正式包前后端使用同一个源地址。采用飞书 v3 服务端 OAuth，以 App Secret 换取令牌；保留五分钟有效、浏览器绑定、一次性 state 及应用和回调地址校验。飞书授权页的 PKCE 暂仅支持 v2 令牌接口，因此本项目不启用 PKCE，也不回退 v2。依据：[飞书授权页说明](https://open.feishu.cn/document/common-capabilities/sso/api/obtain-oauth-code)。迁移 0037 仅清除尚未完成的登录，不影响现有会话。

服务未配置时仅 `/api/healthz` 公开，其他业务拒绝访问。登录入口为 `/api/auth/login`；成功后回到首页。会话 12 小时固定过期，退出会立即删除当前会话；不提供本地密码或开发免登录开关。

## 操作审计

修改操作开始前，API 持久化操作者、操作路由、请求编号和已知对象 ID；成功或失败后补充结果状态、返回的对象/版本及成员角色。审计不保存请求正文、Token、模型指令或报告内容。命名空间管理员可查询全部记录，项目管理者通过 `GET /api/audit?project_id=...` 查询本项目已授权操作。

意图写入失败时普通修改返回 503，业务未执行；取消仍尽力执行并输出带请求编号的服务端告警，需要维护者补查。业务结果与审计完成不是跨 Hatchet/数据库的原子事务：若进程中断或结果写入失败，超过一分钟仍未完成的记录显示 `unknown`，维护者据对象/请求编号检查实际状态，不将其解释为成功或失败。审计页不能自行补写权威成功记录。

## 操作权限

| 操作 | 查看者 | 操作者 | 项目管理者 |
| --- | --- | --- | --- |
| 项目运行、日志、产物读取 | 是 | 是 | 是 |
| 启动运行 | 否 | 是 | 是 |
| 取消运行、编辑或删除计划 | 否 | 本人创建 | 项目内全部 |
| 共享 Agent / 工作流 / 连接维护与发布 | 否 | 否 | 是 |
| 项目成员与角色 | 否 | 否 | 是 |

共享 Agent、工作流、模型连接均可由已登录成员读取；任一项目管理者或工作空间管理员可维护共享定义。模型使用无需项目授权登记；执行任务仍检查所选项目的运行权限。项目列表不向普通成员返回源目录绝对路径。命名空间管理员可登记项目和禁用/启用用户。

禁用用户立即撤销会话与 Token、暂停未来计划；在途运行继续，管理者可以取消。重新启用后需重新登录、重新签发 Token，并由有权限的人显式恢复计划。移除项目成员仅撤回该项目权限、Token 和未来计划，不影响其其他项目。

## API Token 与调用

通过网页登录后调用 `POST /api/auth/tokens`，提供 `project_id`、名称、`scopes` 与不超过 90 天的过期时间。原始 Token 只返回一次，后续查询不回显。每次调用同时核对 Token 范围与用户当前角色，权限不能超出创建者。

浏览器修改操作同时携带与 PUBLIC_URL 相同的 `Origin` 和 `/api/auth/me` 返回的 `X-CSRF-Token`。自动化使用 `Authorization: Bearer <Token>`，不要同时发送会话 Cookie。Token 不允许管理成员或共享配置；带 read 范围可读取共享目录。

节点人工审批、产物人工采纳和报告人工核验必须使用飞书会话；具有 `manage_run` 的 Token 也不能代填。采纳与核验在身份锁内复查最新权限，保留认证来源；历史来源不明的记录不被视为真人评定。GitHub事件入口由项目管理者显式启用，接收端仍复核入口所有者当前权限。

## 共享模型连接

模型连接不属于项目，不再配置 `PANGU_CONNECTION_GRANTS`。配置管理者发布模型连接，Agent 固定引用该版本。OpenAI 兼容连接填写服务地址、模型及 `PANGU_SECRET_` 环境变量引用；真正密钥只存服务端。Codex 连接填写 `provider: codex` 并使用 Worker 的专用登录。

连接版本、归档状态和凭据每次从原始来源重新读取；修改服务外部环境后需要重启服务。不校验项目对模型连接的使用授权，但工作空间隔离、用户登录和项目运行权限仍保留。
