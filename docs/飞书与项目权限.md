# 飞书与项目权限

当前代码已支持后端飞书授权、Pangu 会话和项目权限；真实应用联调需要主机管理员完成以下配置。密钥不放入仓库或聊天。

## 接入配置

在飞书开发者后台创建自建应用，启用网页登录并登记精确回调：`PANGU_PUBLIC_URL/api/auth/callback`。只使用基础身份信息，不申请通讯录全量同步、文档或消息权限。

| 环境变量 | 含义 |
| --- | --- |
| `PANGU_PUBLIC_URL` | 浏览器访问的源地址，无路径或末尾斜杠；远程必须 HTTPS，本地允许回环 HTTP |
| `PANGU_FEISHU_APP_ID` / `PANGU_FEISHU_APP_SECRET` | 当前自建应用身份，Secret 仅 API 服务持有 |
| `PANGU_FEISHU_TENANT_KEY` | 唯一允许的飞书租户 |
| `PANGU_FEISHU_ADMIN_OPEN_ID` | 明确指定首位管理员在当前应用下的 open_id |

开发时若页面位于 `http://localhost:5180`，PUBLIC_URL 使用该地址，由 Vite 将 `/api` 转发到后端。正式包前后端使用同一个源地址。飞书 v3 与 PKCE 必须通过真实应用联调；不会回退旧 v2 接口。

服务未配置时仅 `/api/healthz` 公开，其他业务拒绝访问。登录入口为 `/api/auth/login`；成功后回到首页。会话 12 小时固定过期，退出会立即删除当前会话；不提供本地密码或开发免登录开关。

## 操作审计

修改操作开始前，API 持久化操作者、操作路由、请求编号和已知对象 ID；成功或失败后补充结果状态、返回的对象/版本及成员角色。审计不保存请求正文、Token、模型指令或报告内容。命名空间管理员可查询全部记录，项目管理者通过 `GET /api/audit?project_id=...` 查询本项目已授权操作。

意图写入失败时普通修改返回 503，业务未执行；取消仍尽力执行并输出带请求编号的服务端告警，需要维护者补查。业务结果与审计完成不是跨 Hatchet/数据库的原子事务：若进程中断或结果写入失败，超过一分钟仍未完成的记录显示 `unknown`，维护者据对象/请求编号检查实际状态，不将其解释为成功或失败。审计页不能自行补写权威成功记录。

## 操作权限

| 操作 | 查看者 | 操作者 | 项目管理者 |
| --- | --- | --- | --- |
| 项目运行、日志、产物和配置读取 | 是 | 是 | 是 |
| Agent / 工作流草稿、发布、启动运行 | 否 | 是 | 是 |
| 取消运行、编辑或删除计划 | 否 | 本人创建 | 项目内全部 |
| 共享模板维护与发布 | 否 | 否 | 是 |
| 项目连接、成员与角色 | 否 | 否 | 是 |

共享模板可由已登录成员读取；模板绑定时仍检查目标项目权限。连接详情仅管理者可读。项目列表不会向普通成员返回源目录绝对路径。命名空间管理员可登记项目和禁用/启用 Pangu 用户；飞书成员状态不自动同步。

禁用用户立即撤销会话与 Token、暂停未来计划；在途运行继续，管理者可以取消。重新启用后需重新登录、重新签发 Token，并由有权限的人显式恢复计划。移除项目成员仅撤回该项目权限、Token 和未来计划，不影响其其他项目。

## API Token 与调用

通过网页登录后调用 `POST /api/auth/tokens`，提供 `project_id`、名称、`scopes` 与不超过 90 天的过期时间。原始 Token 只返回一次，后续查询不回显。每次调用同时核对 Token 范围与用户当前角色，权限不能超出创建者。

浏览器修改操作同时携带与 PUBLIC_URL 相同的 `Origin` 和 `/api/auth/me` 返回的 `X-CSRF-Token`。自动化使用 `Authorization: Bearer <Token>`，不要同时发送会话 Cookie。Token 不允许管理成员或共享模板。

## 项目模型凭据登记

主机管理员在 API 与 Worker 环境提供同一份非敏感授权登记，密钥值只在 Worker 环境提供。下面的 UUID 与模型名必须替换成实际配置；程序不会自动加载 `.env.example`。

```json
[
  {
    "project_id": "00000000-0000-0000-0000-000000000001",
    "base_url": "https://model.example/v1",
    "secret_ref": "PANGU_SECRET_PROJECT_MODEL",
    "models": ["approved-model"]
  }
]
```

上述 JSON 存在 `PANGU_CONNECTION_GRANTS`；`PANGU_SECRET_PROJECT_MODEL` 存真正凭据。连接 API 只能引用登记中一致的项目、地址和模型。发布与调用时读取当前进程环境，改变操作系统外部环境后需显式重启相关服务；不声称跨进程环境自动刷新。数据库中的连接版本与归档状态每次调用重新读取。
