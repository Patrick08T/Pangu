# 可视化编排使用

进入“自动化 → 可视化编排”，或打开 http://127.0.0.1:8081/#/workflow 。点击“创建工作流”，无需编写或上传 JSON。

## 创建和运行

1. 填写名称，点击左侧已发布助手加入画布。Eino 与 Codex 可以混合使用；每个步骤立即固定助手版本。
2. 拖动卡片调整位置。从前一步右侧圆点连接到下一步左侧圆点；也可依次点击两个圆点，或在右侧“前置步骤”勾选。多条前置连线表示等待全部上游。
3. 点击步骤，在右侧填写名称，设置字段映射、执行条件或人工审批。“更换助手或版本”需要明确选择，已有流程不会自动升级。
4. “流程输入与预算”可通过字段表单定义输入。加入产品经理助手时会自动带入产品需求字段。预算不填时使用现有默认上限。
5. 点击“保存草稿”。不完整流程可保存；发布前需处理问题清单。保存失败或修订冲突会保留本地编辑，离开页面前会提醒。
6. 保存成功后点击“发布”，再点“运行此版本”。填写运行输入，检查环境后开始执行。历史版本可查看只读画布，也可创建定时计划；定时计划用下拉列表选定发布版本、表单填写输入，不要求手填版本 ID 或编排 JSON。

## 画布操作

- 拖动节点，或选中节点后用方向键调整位置；Delete / Backspace 删除选中元素。复制、删除和自动排列也有普通按钮。
- 左下角缩放和适配按钮、右上角“查看全图”用于调整视图。保存草稿后，节点位置和视图可恢复。
- 撤销、重做覆盖本次未保存的画布与设置修改；成功保存后以服务端返回的草稿为新起点，清空撤销历史。
- 删除连接不会悄悄删除字段映射；需要修复失效引用后才能发布。引用已声明字段时，字段删除、改名或类型不一致会显示问题。
- 归档工作流保留历史版本，恢复后重新读取服务端草稿。只读成员不能编辑或发布。

## 助手字段与节点调试

- 在“助手 → 配置 → 输出字段”勾选“声明结构化输出”，使用表单添加字段，再保存并发布助手。工作流仍须显式选用新版本，原发布版本不变。
- 点击画布节点，可查看固定助手的职责、产品经理任务方式和文件能力。Eino 使用 Codex 账号作为模型时，工具仍由 Eino 管理；原生 Codex 才有对应项目工作区执行能力。连接方式详情仅对有权限的项目管理者读取。
- 在“输入字段映射”中选择数据来源和字段，类型自动匹配。字段名称不需要写 JSON Pointer；数组索引或未声明结构的引用可在“高级路径”中填写。只读发布版本同样能展开查看路径。
- 在“任务记录 → 任务详情 → 执行过程与日志 → 节点调试”点击节点，在右侧查看输入、结果、错误和实际尝试证据。历史较多时可分页；排队节点不会生成虚构的尝试记录。

## 范围与限制

每个流程最多 32 个 Agent 步骤，支持无环串并行、条件执行、人工审批、变量映射和调用预算。循环、子流程、互斥分支汇合、独立脚本节点及多人实时协作不在本次范围。

条件只支持布尔值或字符串精确匹配。任一直接上游跳过时，后续依赖步骤也会跳过；将互斥分支接在一起不会实现“任意分支完成就继续”。助手未声明输出结构时，手填字段路径仍须通过运行时校验。

画布不会改变 Hatchet 节点调度、重试和恢复语义。保存与发布不会调用模型；实际运行仍使用已配置账号、执行策略与预算。
