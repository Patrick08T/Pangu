| 发现 | 处理与验证 |
| --- | --- |
| 项目验收失败原本终止流程，阻止正常返修 | 循环的前置阶段保留中间补丁；质量门将明确的验收非零退出码转换为 `passed:false`。取消、进程停止未确认、工具启动异常仍返回错误。 |
| 旧轮成功结果可能被显示或复用 | 前后端仅选择各循环当前轮结果；检查点续跑拒绝旧轮验收；修改循环定义后不能沿用旧前缀。 |
| 干净检查点导致 OCR 默认审查列表为空 | 明确从 `revision.origin_commit` 比较到 `revision.head_commit`。Perforce 质量门获得只读外部快照目录，通过指定提交读取累计差异及完整上下文。 |
| 平台验收失败可能与完整报告中的“通过”矛盾 | 同步修正摘要、完整报告与内容哈希，保留原始说明和工具证据。 |
| 历史执行详情错误展示当前输入 | 查看旧轮时停止请求并隐藏当前输入预览，明确提示使用所选执行的追踪和证据。 |
| 日志过期后的终态摘要缺少循环轮次 | 归档保留循环 ID、轮次和模型重试编号，不保留过期正文；实际 Hatchet 测试先失败、修复后通过。 |

本轮未发现尚未修复的阻断问题。
