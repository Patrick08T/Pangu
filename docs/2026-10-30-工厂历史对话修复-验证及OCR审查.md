## 问题与根因

工厂助手侧栏显示“未知查询参数”，无法列出已有对话。前端请求携带正确的 `project_id` 和 `offset`，但后端工厂列表调用了共享目录的 `catalogQuery`，将 `project_id` 判为未知参数，在访问历史数据之前返回 HTTP 400。

## 修复范围

- 新增项目列表参数解析：仅接受唯一、非空的 `project_id` 与 `offset`，验证 UUID 和非负整数，并拒绝溢出数值。
- 工厂、交付、评测用例和 GitHub 钩子列表要求项目；审计与定时任务列表仍允许省略项目，保留原权限判断。
- 共享目录的参数范围保持独立，项目列表不接受 `kind`、`archived` 等共享目录参数。
- 存储层及前端无需修改。本次没有删除、迁移或重建历史对话。
- 修正工厂和调度器的两处测试调用，补充前一轮 `catalog.List` 新签名要求的归档筛选参数 `nil`，保留原测试语义。
