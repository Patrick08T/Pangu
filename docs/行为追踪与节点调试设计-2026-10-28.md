# Pangu 方向调整、行为追踪与节点调试

## 已确认目标

Pangu 聚焦可管理、可恢复、可验收的研发工作流。保留项目、固定版本、Hatchet 调度、独立工作区、审批与交付证据；本轮不接入新的 Agent 引擎或插件框架。

用户确认取消工具调用次数、单工具时限、节点/会话/整次运行时限及固定 Codex 并发上限。项目权限、沙箱、资料授权、工作区隔离、主动取消和显式调用预算继续生效。重试策略、请求/产物大小和基础设施连接超时不属于本次取消范围。

调试粒度为工作流节点：暂停阻止尚未开始的节点，已经开始的节点正常收敛；单步只放行一个就绪节点，再回到暂停状态；继续恢复正常调度。单步不跳过人工审批，不绕过依赖和权限，不提供工具级断点或强行挂起操作系统进程。

采用 TDD；本项目继续 Git-only，豁免 P4。完成后使用 OCR 审查。

## 行为追踪

使用原有 PostgreSQL 产品库保存追加事件，以运行、节点、节点运行、尝试、span 和父 span 关联。记录节点、模型请求、工具调用的开始/完成、输入摘要、输出、耗时、错误及截断标记。数据在写入前脱敏，不记录认证头、凭据或模型内部推理。

未设置 budget 时取消默认模型/搜索/Codex 会话额度，用户主动填写的预算继续执行。Hatchet 0.110.5 必须使用有限超时，使用最大 duration 经 SDK 转换后的整秒值 9223372036s（约 292 年）；Eino 0.9.22 使用 math.MaxInt。无需修改第三方引擎，主动取消保持有效。

控制台复用任务详情和节点调试页，提供实时轮询、按节点和事件类型过滤、事件详情及导出。读取沿用项目权限，控制沿用运行管理权限和审计。追踪正文跟随运行正文到期清理；执行中保护规则保持不变。

Codex 复用固定版本原生构建，在真实模型/工具边界输出结构化事件；取消原有工具计数器和终止计时器。Eino 在现有模型和工具调用边界采集。执行器不以模型声称的操作替代真实工具事件。

## 影响范围

- 执行：workflow 策略、agent、research、scheduler、原生 Codex 补丁与构建检查。
- 控制：execution 的持久节点闸门，运行 API、权限、取消、恢复和清理。
- 展示：OpenAPI、生成前端类型、Agent 配置、工厂候选预览、任务详情和调试页。
- 资料：示例模板、工厂指令、运行契约、产品方向和验收记录。
- 验证：无固定工具上限、调用方取消、跨运行并行、节点单步竞争、暂停恢复、追踪关联/脱敏/分页/清理、API 权限、前端行为及真实 Codex 对本地模拟服务的集成。
