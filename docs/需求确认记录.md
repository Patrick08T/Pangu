## 1. 本次明确调整

### Q17：Agent 模板跨项目，绑定后不可迁移

- 2026-10-28 更新：Agent 角色、工作流、模型连接均为工作空间共享定义，与项目分开。发布工作流不创建项目角色副本。
- 运行时选择项目，使用其代码、权限和环境；模型连接无需项目使用授权。迁移仅合并配置完全相同的副本，保留不同配置和历史版本引用。
- 绑定固定模板版本；模板后续发布不自动升级已绑定 Agent。项目参数、模型连接、工作区和运行记录留在对应项目，不能随模板跨项目泄露。
- 共享模板只含通用角色、指令、参数结构和工具能力声明；管理者发布共享模板，使用者仍须有目标项目权限。项目操作者可维护本项目配置，不因此获得共享模板管理权限。
- 工作流和模型连接继续按项目归属。归档禁止新绑定，已有版本引用继续有效；紧急停止使用显式暂停/禁用。

### Q21：首个 Eino Agent 是产品经理

产品上提供“产品经理”角色，技术上由一个 Eino Agent 模板及受控工具实现。不是把角色名称当成没有实际工具能力的提示词，也不因此新增执行器。

| 能力 | 输入 | 交付 | 工程任务 |
| --- | --- | --- | --- |
| 调研 | 研究问题、目标用户、市场/时间范围、授权资料 | 来源清单、带引用的调研报告、事实/推断/未知项 | C13 |
| 竞品分析 | 指定竞品或调研候选、比较维度 | 竞品矩阵、定位差异、优势/不足及证据 | C14 |
| 产品规划 | 调研证据、目标、约束 | PRD、范围、优先级、路线图和可衡量验收指标 | C15 |
| 方案设计 | 已确定范围、产品约束、用户需求 | 用户流程、功能方案、边界/异常、验收条件与可独立执行任务 | C16 |

四类能力可分别调用，也可以使用同一角色的不同能力组成 DAG；编排中的每个节点仍由 Hatchet 独立调度与恢复。输出使用中文；信息不足时明确标记未知或假设，不编造市场数据、竞品价格或引用。

底层工具至少支持受控公开信息搜索、网页正文读取、授权项目资料读取和报告产物登记；保留 URL、标题、访问时间及可获得的发布日期。搜索服务及凭据在 C09 实现前落实，不暗自购买或替用户选收费供应商。网页内容是资料，不能授权 Agent 执行命令、读取额外私密数据或外发项目内容；限制重定向、内网目标、响应大小与执行时间。

长报告保存为项目产物，节点返回摘要和产物引用，继续遵守现有 16 KiB 节点输出限制。默认不直接发布到飞书文档、发送消息或写入用户源项目。

首个对外提供的 Eino 专业角色是产品经理；已有“小范围修改与验证”“只读项目巡检”工作流仍保留，共三类可使用模板。

### Q23：使用飞书登录

采用飞书网页登录授权，后端完成身份获取并建立 Pangu 自身会话；不开发本地密码登录或另一个默认认证来源。飞书官方概述将浏览器登录划分为授权跳转、后端取得用户访问令牌、获取用户身份和建立应用登录态。[飞书登录概述](https://open.feishu.cn/document/client-docs/build-login-free-system-)

Pangu 仍负责项目成员、管理者/操作者/查看者、会话与 API Token 的授权和撤销。飞书身份验证成功不自动获得项目访问或管理员身份；管理员初始化与允许的组织/成员范围需要显式配置。身份绑定使用服务端验证的稳定身份标识，不使用昵称或前端自报字段作授权依据。

U01 验证回调关联、防重放、错误回调、非允许组织/成员、会话失效和登录入口；具体权限范围和回调配置以实施时官方规范为准。App Secret 仅服务端保存，不进入浏览器、仓库、运行快照或日志。这里只使用登录能力，不自动申请通讯录全量读取、文档写入或消息发送权限。

## 5. 2026-10-25 易用性调整确认

用户反馈产品无法顺畅使用，并确认本次简化方案：以新建任务、任务记录、助手、自动化为主导航；高级能力归入设置；从当前项目最新发布版本直接选择助手；单按钮完成预检和提交；规划和设计只要求任务目标，背景选填；调研来源与竞品分析的必要信息仍须显式提供；结果默认展示报告，日志按需展开。助手准备提供角色表单，任务记录显示可读标题。

本次变更覆盖此前产品经理背景字段全部必填的约定，不改变项目权限、发布版本、数据来源授权、幂等提交和保留期限。标题不进入长期运行归档，输入过期后不再展示。继续使用 Git、TDD 和原生 Codex 审查；真实模型预算与搜索凭据的外部待办仍按 Q04 等既有约定处理。验收和非目标见 [易用性 PRD](PRD-Pangu易用性.md)。
