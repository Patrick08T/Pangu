# Agent 执行状态与详情

任务详情主区域展示工作流所有节点的状态图，点击节点后，详情覆盖右侧整个主内容区，左侧导航仍可使用。同一个角色在多个阶段执行时按节点分别展示，避免把不同阶段的记录混在一起。

## 查看方式

- 状态卡片展示节点标识、执行器、职责说明、状态、尝试次数、依赖和当前活动；顶部汇总执行中、完成、失败和跳过的节点数量。
- 详情展示当前操作、开始时间、持续时间、请求或工具参数摘要，以及该节点的执行时间线、职责与指令、输入、输出、错误和重试证据。
- 时间线只查询所选节点，可按模型请求、工具调用或状态过滤、查看更早记录及导出。顶部固定显示“返回任务”按钮，返回时保留选中节点，恢复流程图与页面滚动位置，并将焦点返回节点卡片。重新打开详情会重置时间线筛选与分页。
- 当前活动及最新 trace 每 2 秒更新，节点状态沿用任务详情每 5 秒更新。历史分页暂停自动刷新；停止或日志过期后不再轮询当前活动。

## 状态来源与边界

新增 `GET /runs/{id}/activity`，沿用运行读取权限和日志保留期。查询只读取未结束的真实节点尝试，按尝试和 span 匹配最新事件，再返回各节点最近开始且尚未结束的操作。历史记录超过一页时仍可识别长调用；已结束工具、旧尝试及停止节点不会显示为当前活动。并行操作的完整记录通过节点时间线查看。

没有活动数据时不推断 Agent 的内部行为，明确提示等待记录；请求失败时清除当前活动展示并提示无法确认。记录复用入库前脱敏，不保存或展示模型内部思维链。未修改角色、工作流定义或节点调试语义，不新增数据库迁移或配置缓存。
