# 控制台界面设计

控制台服务于可信小团队日常配置、运行、审查与追溯。沿用已有 Pangu 蓝灰视觉，主要信息用表格、文件差异和有方向的节点图表达；不增加营销首屏或虚构统计数字。

## 视觉与结构

- 背景 `#f6f7f9`，正文 `#253347`，主操作 `#233e63`，边界 `#dce3ec`，完成 `#198268`，警告 `#95601c`。
- 中文采用 Microsoft YaHei，拉丁文字使用 Segoe UI；代码与 JSON 用等宽系统字体，不下载外部字体。
- 桌面固定左侧项目与导航，内容左对齐；运行列表以状态、时间和任务标识为主，详情按“节点 → 证据 → 产物”展开。表单与 JSON 编辑有明确标签、错误和保存状态。
- 只读 DAG 采用按执行层分组的有向节点关系，并提供文字依赖列表；状态同时使用文字和颜色。32 节点可滚动与键盘访问，不提供拖拽编排。
- 窄屏导航换行，表格局部滚动；正文与错误可换行，焦点可见，所有内容按文本展示。

```text
项目 / 导航        页面标题、当前用户与角色
运行              筛选与主操作
Agent / 流程      列表 / 草稿编辑 / 详情
定时计划          当前结果与分页
成员 / 连接       错误、空状态与下一步
审计 / 环境
```

对比初始状态页：保留环境状态卡作为诊断入口；业务页面采用表格和可展开细节，避免把每个操作都装入相同卡片。飞书未配置与未登录分开提示；不会显示示范项目或假运行。

## 请求行为

前端只访问同源 `/api`；会话 Cookie 为 HttpOnly，CSRF 取自当前身份。权限按钮只用于提示，后端始终重新授权。运行每 5 秒刷新，离开页面或页面隐藏时停止无用轮询；失败保留可辨识的错误和重试入口。

提交与重新运行保留同一操作的幂等键，重复点击不生成第二次运行；结果未知时用相同键重试，不把超时当作失败。取消中的运行保留“取消中”状态；重新运行明确使用原定义和原基准创建新运行。计划编辑提交修订号，冲突提示重新读取，不自动覆盖。
