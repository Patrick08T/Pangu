## 已验证

- 测试先行：JSON 校验、稳定分层、依赖传递、Eino 调用及 HTTP 接口。
- `go test ./...`、`go vet ./...`、构建通过；Go AST 检查全部函数不超过 70 行。
- 官方 sidecar 原生 Windows 编译、PostgreSQL 初始化及迁移成功。

- API → Hatchet → Eino 使用本地模拟模型 HTTP 服务跑通。
- 节点独立重试：上游调用 1 次，故意失败的节点调用 2 次，下游调用 1 次。
- Worker 强制终止后重启：原运行恢复，已完成节点未重复调用。
- Cron 创建、列出、按分钟真实触发、删除成功。
- 大输入问题先复现了 4 MiB gRPC 消息超限；改为逐个派生后，200 KiB 输入、32 个独立节点通过。
- 首次启动的工作流注册竞态：先复现未知工作流返回 202 但没有实际运行；提交前直接检查注册状态，未注册返回 503。外部 Worker 恢复测试等待就绪后提交，已通过。
- 历史节点查询：先复现新运行后旧运行的 32 个节点只返回 31 个；改用支持父任务筛选的工作流查询，并显式请求节点输入和输出。
- API 自定义端口：先验证 `-port 8081` 不被识别；新增端口参数后，前台启动的健康检查、历史运行和三个节点查询、回环监听断言均通过，检查后退出。
